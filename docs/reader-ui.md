# 阅读界面

Mac 网页与 iPhone App 共用 `reader.html`、`ui/reader.css`、`ui/reader-chrome.js`。以用户选定的第二版为视觉依据，参考 Apple Books 的安静阅读面与底部操作；视觉证据见根目录 `design-qa.md`。

- 顶部：书库、当前章节、次要书名、同步状态。书库提供当前书继续阅读、本机导入和已同步书籍入口。
- 底部：当前版式下的章节／分节剩余页数、进度与前后翻页、目录、原文／双语／译文、外观、更多。连续滚动不虚构页数；章节跨多个资源或含内部小节时使用“本节”。翻译设置仍在“更多 → 翻译设置”。
- 目录：桌面侧栏，手机底部抽屉；完成、遮罩和 Escape 可关闭，关闭后焦点返回目录按钮。
- 外观：桌面浮层，手机底部面板；手机面板内保留阅读工具，切换目录、阅读模式或其他面板时先关闭外观，避免目标被模态层阻挡。提供 18–36px 字号、白天／纸色／夜间、翻页／滚动。默认纸色、24px、1.55 行高，沿用紧凑段距；标题层级按字号比例缩放。
- 主题、字号保存在本机 `foliate:appearance`。阅读方式继续使用原有本机存储。外观偏好不上传到 GitHub；书籍、译文及逻辑阅读位置的同步协议保持不变。

## 排版与恢复

流式书籍保留单栏，最大排版宽度 820px。工具展开时桌面上下留白 80px、手机 144px，为章节提示、两行操作及至少 44px 的触控目标留出空间；沉浸阅读时留白缩至 36px。收放通过原有锚点保护重排，默认字号和段距保持不变。页面外壳固定且使用 `overflow: clip`，避免焦点返回工具栏或窗口尺寸变化时滚动整个页面；正文在渲染器内翻页或滚动。

字号和主题改变通过 `PageTranslation.preservePosition()` 捕获、重排并恢复当前字符。改变字号会重新换行，验收保存字符的屏内垂直位置；同设备以相同字号刷新／重开后，仍验收精确段落、字符和滚动偏移。`Paginator.getVisibleRange()` 同步读取当前可见范围，避免滚动事件的 250ms 合并窗口内保存旧位置。

夜间主题将书籍中原有的浅色提示框标记为 `data-foliate-reader-surface`，只调整背景与文字颜色，保留层级、尺寸、对齐、粗斜体和图片。该属性不插入书籍节点，不改变 CFI 或译文缓存键。

iPhone 内置 Noto Serif SC 可变字体作为中文衬线后备，打开书籍前加载到内存，加入各章节的 FontFaceSet；不依赖在线字体或放宽书籍 CSP。Mac 继续优先使用 Songti SC。来源与许可证见 `ui/fonts/README.md`。图标使用 Phosphor Regular，见 `ui/icons/README.md`。

原生 `setAppearance` 仅接受三个已有主题值，在主线程更新 safe area、WebView 背景与状态栏明暗，使纸色和夜间主题覆盖整个手机阅读面；不读取凭据或修改同步设置。

## 本地验收

`npm run check` 覆盖严格 lint、Node 测试、浏览器模块断言、阅读流程与故障拒绝探针。新增 `tests/browser/reader-chrome.spec.js` 验证桌面和手机的字号／主题、原有局部格式、缓存复用、刷新、书库续读、目录焦点、触控尺寸及窗口尺寸切换；另验收真实 EPUB 夜间提示框的颜色和原布局恢复。

iPhone 的浏览器替身仅验证 JavaScript 协议；另运行 `npm run ios:prepare`、Xcode 编译和真机覆盖安装。原生安装、主题与实际阅读结果单独记录在 `docs/iphone-sync.md`，不能由 Chromium 测试代替。

## 沉浸阅读与定位

- 点击正文中间区域收起／恢复工具，底部保留轻量的章节与百分比入口。也可点底部入口或按 Escape 恢复工具；隐藏工具从焦点与点击路径中移除。新打开书籍时显示工具。
- 不拦截链接、表单、修饰键点击、双击、长按、选词和拖动；仅短距离、短时单击触发，双击／选择会取消等待中的单击。
- 进度条 input 只预览目标章节和百分比，不导航、保存或触发目标页翻译；change 提交跳转，取消或失焦撤销预览。预览章节按所在资源显示，不提前加载全文定位章节内部片段。
- 目录和进度跳转前保留逻辑阅读位置；30 秒内可“返回刚才的位置”。返回使用原 CFI 加译文 key / offset / viewportOffset，切书清除临时返回点。它不改变持久书签或缓存键。
- 剩余页数按当前设备、字号、工具状态与已呈现译文的排版计算；翻译扩展或改变排版时自然更新。

## 日常同步面板

默认展示同步结果、当前书名／章节／百分比、最近成功同步时间和“立即同步”。已连接设备折叠连接设置；未连接设备展开配置；已同步书籍独立折叠，书库的对应入口直接展开它。

位置或译文变化后立刻显示“已保存到本机，等待同步”；对应版本提交完成才显示“已同步”。传输中、失败和冲突分别显示，不以旧成功状态代替新进度。冲突保留原有两份位置和显式选择，避免自动按百分比覆盖。最近成功时间只保存在本机同步元数据，不加入 GitHub 协议。

界面证据在 `docs/design/reading-controls/`，使用隔离书籍／模拟服务；真实手机覆盖安装和冲突状态记录见 `docs/iphone-sync.md`。
